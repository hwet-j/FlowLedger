# FlowLedger

내 자산의 들어오고 나가는 모든 기록을 정리하는 Android 가계부. Expo(React Native, SDK 58) + SQLite. 데이터는 이 기기에만 저장돼요.

## 기능
- **여러 통장**(입출금·카드·현금·저축·투자·대출): 잔액은 거래에서 계산, 카드·대출은 음수 잔액(부채). 말이 없으면 **기본 통장(★)** 에 지출이 기록돼요.
- **통장 자동 지정 규칙**: "넷플릭스 → 국민카드"처럼 가맹점·메모·카테고리에 키워드가 있으면 그 통장에 기록. 우선순위는 *직접 지정 > 규칙 > 기본 통장*.
- **카테고리 2단계**(대분류 > 소분류, 직접 추가/수정): 식비(외식·배달·카페/간식·장보기), 쇼핑(의류·…), 취미/여가, 교통, 주거/통신, 건강, 경조사/선물, 교육, 보험/금융, 기타 / 수입 6종.
- **입력**: 지출·수입·이체, 금액 빠른 버튼, 카테고리 칩, 날짜/시간, 가맹점 자동완성(마지막으로 쓴 카테고리 제안), 메모·태그, 저장하고 계속 입력, 길게 눌러 복사.
- **내역**: 월별 날짜 그룹(일 합계), 검색(가맹점·메모·태그·카테고리·금액), 필터(유형·통장·카테고리·전체 기간), **달력 보기**(날짜별 지출 합계).
- **통계**: 월/연, 카테고리별 도넛·순위(소분류 펼침)·전월 대비, 최근 12개월 수입/지출, **월말 기준 순자산 추이**, 통장별·요일별 지출, 많이 간 곳 TOP5, **리포트 공유**.
- **예산**: 전체/카테고리별 월 한도, 진행바, 80%·100% 도달 시 **알림**, 이 속도면 **월말 예상 지출**, 하루 사용 가능액.
- **고정 거래**: 월세·구독·급여 등 매달 자동 기록(밀린 달도 따라잡기, 말일 보정, 중복 방지).
- **자주 쓰는 거래**: 칩 한 번으로 오늘 날짜에 바로 기록(+되돌리기).
- **저축 목표**: 연결 통장 잔액으로 진행률, 목표일까지 월 필요 저축액.
- **앱 잠금**(지문·얼굴·기기 잠금), 다크 모드, 삭제 되돌리기.
- **백업/복원(JSON, 검증 후 한 트랜잭션)**, **CSV 내보내기**(엑셀용 BOM, 수식 주입 방지), 전체 내역 삭제.

## 비서 연동 (앱을 열지 않고 읽기·쓰기)
`modules/assistant-share`(Kotlin ContentProvider, authority `com.hwetj.flowledger.assistant`)가 **같은 SQLite 파일**을 직접 열어 처리해요. 호출자가 비서 앱(`com.hwetj.assistant`)일 때만 응답하고 그 밖은 거부해요. 메서드: `query`(기간별 거래·통장·카테고리·예산·규칙), `add`(멱등 req_id, 통장 미지정 시 규칙→기본 통장), `update`, `delete`, `add_rule`, `delete_rule`. 자세한 규칙과 SQL 은 `tests/provider/`(Python 참조 구현·테스트)와 모듈 소스를 보세요. 앱 잠금은 앱 화면만 보호하며 비서 연동은 별개로 동작해요.

## 딥링크 (`flowledger://`)
`/stats?month=YYYY-MM`, `/tx/<id>`, `/list?month=YYYY-MM&category=<id>`, `/add?type=expense&amount=9000&category=외식&account=국민카드&merchant=…&date=YYYY-MM-DD` (값만 채우고 저장은 사용자가).

## 개발
```bash
npm ci
npx tsc --noEmit && npx eslint .
for tz in Asia/Seoul America/Los_Angeles UTC; do TZ=$tz npx jest; done   # 순수 로직 테스트
python3 -m pytest tests/provider                                          # 제공자 SQL 참조 테스트
```
빌드: GitHub Actions **Build Android APK**(push / 수동 실행) → Releases 의 `FlowLedger APK #N` 을 폰에 설치.
